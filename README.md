# 🐱 ふせん

Googleカレンダーの通知を使う、自分用のリマインドメモ（Google Apps Script ウェブアプリ）。

- `Code.gs` … カレンダー「🐱ふせん」への登録・完了・あとで(再通知)など
- `index.html` … 画面（ドット絵の猫・付箋7色・通知のドラッグ＆ドロップ）

## 使い方
1. [script.new](https://script.new) で新しいプロジェクトを作る
2. `Code.gs` の中身を貼る／`index` という名前のHTMLファイルを作って `index.html` を貼る
3. デプロイ → ウェブアプリ（実行ユーザー：自分／アクセスできるユーザー：自分のみ）
